# 发布产物验证记录

> 本文件用于记录 `npm run release:artifacts`、GitHub Actions artifact 下载和三平台安装验证结果。

## 本地检查

```bash
npm run release:artifacts
```

严格要求 updater 签名文件时：

```bash
npm run release:updater-config
npm run release:artifacts -- --require-updater-signatures
```

检查三平台完整产物目录时：

```bash
npm run release:artifacts -- --all
```

远端 dry-run 验证：

```bash
npm run release:dry-run -- --write-doc
```

或手动执行：

```text
GitHub Actions -> Release Dry Run -> Run workflow
下载 moknow-dry-run-macOS-*、moknow-dry-run-Windows-*、moknow-dry-run-Linux-* artifacts
```

下载后完整性验证：

```bash
npm run release:downloads -- --artifact-root release/downloaded-artifacts --write-doc
```

安装冒烟验证：

```bash
npm run release:install-smoke -- --artifact-root release/downloaded-artifacts --platform all --write-doc
```

生成并检查分发元数据：

```bash
npm run release:metadata -- --require-base-url --require-updater-signatures
```

4. 关闭并重新打开应用，确认最近仓库、文件树和保存内容可恢复。
5. 在命令面板执行“检查应用更新”，正式 updater endpoint 配置前可接受无更新或环境提示。
